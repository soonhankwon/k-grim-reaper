# 0.9.0 첫 인도 사연

## 이야기

첫 임무를 받은 신입 차사는 이름이 빗물에 번진 명부를 받는다. 등불 그림을 단서로 삼아 길을 나서고, 길 잃은 그림자에게서 밤마다 켜 둔 불의 기억을 듣는다. 길에서 찾은 천 조각은 멀리 떠난 가족을 기다린 망자의 마음을 드러낸다. 차사는 이름을 함부로 짐작하지 않고 다시 확인하기로 기록한 뒤 망자와 길을 건넌다.

저승사자의 인도 역할과 차사의 문서 확인이라는 소재를 바탕으로 만든 게임 속 창작이다. 특정 전승이나 지역 의례를 그대로 재현한 이야기는 아니다. 소재 출처와 창작 범위는 [저승사자 참고](lore-reference.md)를 따른다. 새로운 적·아이템·이미지는 추가하지 않았다.

## 표시와 진행

준비·승리·완료 화면에서 아래 사연 카드를 누르거나 상단 **사연**을 눌러 지금까지 공개된 기록을 읽는다. 우측 기록이 열려 있을 때는 스크롤할 수 있으며, 다른 물건을 살펴보면 상세 정보가 우선한다. 상단 버튼을 다시 누르거나 길잡이를 선택하면 기록을 닫는다. 전투 중 카드가 가리는 기록은 없으며 상단 버튼에서 사연을 볼 수 있다.

- `min_completed=0`: 첫 출발부터.
- `1`: 첫 승리의 표시 스냅샷부터.
- `2`: 두 번째 승리의 표시 스냅샷부터.
- `3`: 세 번째 승리 이후 **인도 마치기**로 완료한 뒤.

선택한 경로가 적 순서를 바꾸어도 완료한 길목 수를 기준으로 한다. 재생 중에는 이미 확정된 최종 상태 대신 현재 `display_snapshot()`에서 공개 여부를 계산하므로 결과가 먼저 나타나지 않는다. 연출 건너뛰기는 기존 큐를 통해 최종 표시 상태로 이동한다. 기록을 여닫는 것은 읽기 전용 UI이며 게임 명령·저장·시간 흐름에 개입하지 않는다.

기록 자체의 별도 진행 플래그는 없다. 기존 0.8 저장을 다시 열면 저장된 길목·단계에서 공개 범위를 재계산한다. 텍스트 갱신은 게임 콘텐츠 해시를 변경하지 않으며 게임 화면을 새로 열 때 읽는다. 현재 열린 화면에는 즉시 반영하지 않는다. 사연 변경 후에도 옛 런에서 새로운 문구가 나타날 수 있으므로 출시 후 문구 변경은 주의해서 관리한다.

## 제작 파이프라인

`content/source/story.csv`는 Google Sheets로 가져와 편집할 수 있는 원본이다. 첫 행은 `id,min_completed,title,teaser,text`다. 목록은 중복 없는 영문 소문자 ID, 오름차순 정수 단계(0~64), 비어 있지 않은 제목·요약·본문으로 구성한다. 제목 48자·요약 80자·본문 1000자, 최대 100행이며 첫 행은 단계 0이다. 따옴표·쉼표·줄바꿈은 CSV 표준으로 인용한다.

```bash
python3 scripts/import-story.py
python3 scripts/import-story.py /absolute/path/story.csv
python3 scripts/import-story.py --check
bash scripts/check.sh
```

검증이 성공할 때만 `game/data/presentation/story.json`을 교체한다. 오류 시 이전 JSON을 보존한다. 실행 중에는 원본 CSV가 아니라 JSON을 읽는다. 런타임도 입력 크기·행·중복·텍스트·순서를 검증하며 사연이 없거나 잘못되면 사연 표시만 비활성화하고 전투는 유지한다. Google 계정 업로드·네이티브 시트 동기화는 제공하지 않는다.

`story_ui_smoke.gd`는 표시 시점·경로 순서·결말 전 비노출·스크롤·화면 경계·기존 저장과 재실행을 확인한다. 가져오기 검사는 잘못된 원본이 기존 JSON을 덮어쓰지 않는지 확인한다. 이는 실제 플레이어가 사연을 이해하거나 감정적으로 반응한다는 검증을 대체하지 않는다. 첫 유품 사건은 선택에 따라 후속 대사와 회복이 달라진다. 추가 대사 분기·유품 잠금·난수 이야기는 아직 구현하지 않았다. [유품 사건](event-flow.md)
