# 0.11.0 전투 피드백

기존 픽셀 캐릭터를 사용해 아이템 행동 시 신입 차사가 짧게 움직이고, 피해를 받은 대상만 밀리며 색이 변한다. 해당 대상 위에 실제 체력 피해, 방어로 전부 막은 피해, 방어 증가·설정, 실제 회복량을 표시한다. 피해 수치는 방어로 흡수된 양과 구분하고, 회복 수치는 최대 체력으로 제한된 실제 증가량을 사용한다. 반사 피해도 대상 필드에 따라 차사 쪽에 표시한다.

0.17.0에서는 처치 먹선·한기·컷신·임시 효과음을 추가했다. 프레임별 전투 애니메이션은 아직 없다. 자세한 범위와 제약은 [연출 파이프라인](cinematic-presentation.md)에 기록한다.

## 시간과 상태

한 이벤트의 `CombatEventCommand`가 Tween을 소유한다. 명령이 시작될 때까지는 이전 표시 상태를 유지하며, 타격 지점에서 이벤트의 `after` 스냅샷을 적용한다. 같은 시점부터 피해 숫자가 보이고 체력바·보따리·메시지도 그 스냅샷으로 갱신된다. 이후 잠시 연출이 이어진 뒤 명령이 완료되고 다음 이벤트를 재생한다. UI 메시지는 `event_started`가 아니라 `event_presented`를 받는다.

피해·방어·회복은 표시 시간을 조금 더 확보한다. 이 시간은 게임 판정이 아니라 연출 시간이며 `연출 건너뛰기`는 즉시 최종 표시 상태로 맞춘다. 캐릭터 표현과 수치는 표시용 스냅샷과 이벤트만 읽고 확정 상태를 다시 계산하거나 변경하지 않는다. 실제 체력·방어·소모가 적용되는 순서는 기존 순수 FIFO와 원인 ID를 따른다.

즉시 완료나 중복 완료는 한 번만 처리한다. 건너뛰기·재시작·타임아웃·장면 종료에서는 Tween을 정리하고 색상·위치·수치를 초기화한다. 피드백 뷰가 먼저 사라져도 남은 이벤트는 정상 완료한다. 표시 갱신 도중 재시작된 경우 과거 이벤트 메시지를 내보내지 않는다.

## 검증

`feedback_tests.gd`는 표시 이전 체력 유지, 실제 피해·방어 차단·회복 상한, 플레이어 반사 피해, 공격→반사→방어의 FIFO와 스냅샷, 즉시 완료·중복 타격·건너뛰기·재시작·타임아웃·뷰 및 장면 제거를 확인한다. 기존 UI 검사는 피해 메시지와 체력 표시가 타격 전에 나오지 않는지도 검사한다. `feedback_capture.gd`는 선택적으로 실제 Godot 렌더러의 한 프레임을 캡처한다. Windows 입력·배율과 플레이어가 각 효과를 쉽게 구분하는지는 별도 검증한다.
