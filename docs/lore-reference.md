# 저승사자 소재 참고와 게임 적용

작성: 2026-10-26 · 목적: 세계관·소지품·외형의 기준 정리

## 자료 확인 상태

- 사용자 지정 참고: [나무위키 — 저승사자](https://namu.wiki/w/%EC%A0%80%EC%8A%B9%EC%82%AC%EC%9E%90). 이 환경의 사이트 접근 정책으로 원문을 읽지 못했다. 아래 내용은 해당 문서를 요약한 것이 아니다.
- 직접 확인: 한국민족문화대백과사전의 [저승사자](https://encykorea.aks.ac.kr/Article/E0072772), [차사본풀이](https://encykorea.aks.ac.kr/Article/E0055151), [저승설화](https://encykorea.aks.ac.kr/Article/E0049101), 우리역사넷의 [초종 의식의 사잣밥과 죽부의](https://contents.history.go.kr/front/km/print.do?levelId=km_010_0050_0040_0020&whereStr=).
- 지역별 신앙·의례와 이본에는 차이가 있다. 특정 지역의 설명을 한국 전체의 단일 규칙으로 확대하지 않는다. 게임 적용은 확인한 소재를 바탕으로 한 창작 제안이다.

## 확인한 소재와 적용 방향

| 소재 | 자료에서 확인한 내용 | 게임에 적용할 창작 방향 |
|---|---|---|
| 인도하는 역할 | 저승사자를 죽은 이를 저승으로 데려가는 매개자로 설명한다. [저승사자](https://encykorea.aks.ac.kr/Article/E0072772) | 신입 차사의 업무를 대상 확인·길 안내·인계로 구체화. 전투는 인도 중의 장애를 해결하는 수단 |
| 적패지·오라 | 제주 차사본풀이의 구연 정황에서 차사는 적패지와 오라를 지니고 본향당신을 통해 대상 명부를 확인한다. [차사본풀이](https://encykorea.aks.ac.kr/Article/E0055151) | 임무 문서·포박 도구를 대표 소지품 후보로 삼고, 배치 조건과 전투 행동에 연결 |
| 인간에서 차사로 | 같은 본풀이는 이승의 강림이 차사가 되는 내력을 다룬다. [차사본풀이](https://encykorea.aks.ac.kr/Article/E0055151) | 초보의 적응과 성장에 참고. 주인공은 별개의 창작 인물로 유지 |
| 실수와 인간적 면모 | 저승설화에는 판관·사자의 실수와 인간적인 면모도 나타난다고 설명한다. [저승설화](https://encykorea.aks.ac.kr/Article/E0049101) | 문서 착오·동명이인 확인 같은 짧은 사건과 신입의 실수에 활용 |
| 복식의 여러 표현 | 대중적인 검은 두루마기·갓 이미지와 굿에서의 군졸 모습 등을 구분한다. [저승사자](https://encykorea.aks.ac.kr/Article/E0072772) | 검은 갓·먹빛 겉옷을 게임의 시각적 선택으로 명시하고, 전체 인물에 동일한 복식 원칙 적용 |
| 사잣밥·짚신·동전 | 사자상에 밥·짚신·동전을 차리는 사례와 차림의 차이를 설명한다. [우리역사넷](https://contents.history.go.kr/front/km/print.do?levelId=km_010_0050_0040_0020&whereStr=) | 회복 음식·여정 장비·노잣돈과 대접받는 사건에 활용 |
| 해학 | 사자거리의 해학·풍자가 천도굿 분위기를 전환하는 역할을 설명한다. [저승사자](https://encykorea.aks.ac.kr/Article/E0072772) | 선배와 신입의 업무 대화에 유머를 배치하고, 망자의 사연에는 별도의 정서 유지 |

## 세계관에 반영하는 원칙

1. 주인공의 직무 호칭은 신입 차사로 두고, 플레이어 소개에서는 익숙한 저승사자라는 표현을 함께 쓴다.
2. 이 게임의 주인공은 인도 임무를 수행한다. 최종 심판과 인계 이후의 처리는 저승의 별도 권한으로 설정한다. 임무 중 문서와 실제 사연이 어긋날 때 확인하고 선택하는 것이 갈등이다.
3. 찢긴 자신의 명부, 지워지는 이름, 유품을 받아주는 보따리, 마음매듭 변환, 선배의 구조와 귀환은 우리 게임의 창작 설정으로 기록한다.
4. 제주 차사본풀이와 다른 지역의 표현을 함께 참고할 때 그 조합 자체가 창작임을 분명히 한다. 사자 수·관직·복식을 하나의 보편 규칙으로 단정하지 않는다.
5. 등장인물 수를 늘리지 않고 기존 주인공·선배·서리의 역할과 대사에 소재를 반영한다.

## 아트와 아이템 적용

주인공은 갓·먹빛 겉옷·허리의 문서·작은 보따리로 실루엣을 잡는 안을 우선 검토한다. 장식의 수를 제한하고, 신입다운 작은 장비와 덜 익숙한 행동은 같은 픽셀·명암 규격 안에서 표현한다. 이 외형은 미술 방향이며 전통 복식의 유일한 정답으로 설명하지 않는다.

데모 아이템 16개 안에서 **적패지, 오라, 짚신, 사잣밥** 모티프를 우선 후보로 검토한다. 도입 시 공격·방어·회복·비용 등 기존 효과를 활용하고, 각 소재마다 새 시스템을 추가하지 않는다. 명칭·점유 크기·효과는 아이템 목록 확정 때 결정한다.

기존 사인검·봉인부·방울은 게임용 전투 장비다. 이번 자료 확인만으로 저승사자의 전형적인 소지품으로 확정하지 않는다. 혼백등·유품 시너지·마음매듭의 기능도 게임 창작으로 관리한다. 자료에 이름이 나온다는 것과 게임 속 능력이 전승에 있다는 것을 구분한다.

## 개발 플랜 연결

- M3의 기존 아트 기준 시트 작업에 복식·소지품의 출처와 창작 구분을 포함한다.
- 아이템 6개 샘플 중 적어도 일부는 직무가 드러나는 문서·줄·여정 소품으로 잡고 게임 내 판독성을 확인한다.
- M4의 첫 사연에 대상 확인과 유품 인도의 의미를 드러내는 짧은 대사를 넣는다.
- 새로운 지역·등장인물·아이템 수를 추가하는 근거로 사용하지 않는다. 현재 범위 안에서 이름·시각 표현·사건 내용을 구체화한다.
