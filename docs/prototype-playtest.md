## M2 배치의 재미 — 외부인 3~5명

플레이어마다 처음 5분은 진행자가 정답 배치를 알려주지 않는다. 이후 막힌 부분을 함께 살펴보고 두 번째 배치를 시도하도록 요청한다. 작은 표본으로 시장성을 단정하지 않는다.

1. 첫 화면을 보고 준비를 마친 뒤 한 턴을 진행한다.
2. 아이템 위치를 바꿔 효과가 달라지는 사례를 찾는다.
3. 세 길목을 통과하거나 실패 원인을 설명한다.
4. 처음과 다른 배치로 다시 시도한다.

## 내부 재현용 배치

좌표는 보따리 왼쪽 위를 `(0,0)`으로 한다. 외부 테스트 시작 전에 정답처럼 제공하지 않는다.

- 첫 길목 방어 배치: 봉인부 `(2,1)`, 옥가락지 `(0,0)`. 가호 4와 갓 방어 5를 활용하고 검·방울로 공격한다. 두 번째 보상에서 엽전을 골랐다면 `(1,1)`에 놓아 가호 8을 만들 수 있다.
- 보상 후 공격 배치: 첫 보상에서 오라, 두 번째에서 적패지를 획득한 뒤 모두 보관대로 옮기고 검 `(1,0)`, 봉인부 `(2,1)`, 오라 `(3,0)`, 적패지 `(0,0)`, 방울 `(0,2)`. 회전은 모두 0°. 검+적패지로 기력 3을 사용한다. 봉인부는 검과 오라 양쪽에 적용된다.

기존 회귀 검사는 초기 12개 고정 픽스처의 두 배치를, 보상 검사는 초기 7개에서 보상 2회를 거쳐 완주하는 흐름을 확인한다. 위 배치는 내부 재현을 돕는 사례다. 균형이 적절하다거나 서로 다른 재미가 있다는 증거로 사용하지 않는다.
