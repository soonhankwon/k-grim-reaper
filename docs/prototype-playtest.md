## M2 배치의 재미 — 외부인 3~5명

플레이어마다 처음 5분은 진행자가 정답 배치를 알려주지 않는다. 이후 막힌 부분을 함께 살펴보고 두 번째 배치를 시도하도록 요청한다. 작은 표본으로 시장성을 단정하지 않는다.

1. 첫 화면을 보고 준비를 마친 뒤 한 턴을 진행한다.
2. 아이템 위치를 바꿔 효과가 달라지는 사례를 찾는다.
3. 세 길목을 통과하거나 실패 원인을 설명한다.
4. 처음과 다른 배치로 다시 시도한다.

| 관찰 | 기록 |
|---|---|
| 도움 없이 전투를 시작했는가 | |
| 물건 클릭 사용과 턴 종료를 구분했는가 | |
| 첫 인접 효과를 발견한 시점·물건 | |

| 정리가 선택으로 느껴졌는가, 반복 작업으로 느껴졌는가 | |
| 스스로 재도전했는가 | |

## 내부 재현용 배치

좌표는 보따리 왼쪽 위를 `(0,0)`으로 한다. 외부 테스트 시작 전에 정답처럼 제공하지 않는다.

- 방어 배치: 초기 상태에서 봉인부 `(2,1)`, 옥가락지 `(0,0)`, 엽전 `(1,1)`. 가호 8을 받고 검·방울·갓·엽전을 사용한다.
- 공격 배치: 모두 보관대로 옮기고 검 `(1,0)`, 봉인부 `(2,1)`, 오라 `(3,0)`, 적패지 `(0,0)`, 방울 `(0,2)`. 회전은 모두 0°. 검+적패지로 기력 3을 사용한다. 봉인부는 검과 오라 양쪽에 적용된다.

두 배치는 자동 검사에서 생존·완주를 확인하기 위한 사례다. 균형이 적절하다거나 서로 다른 재미가 있다는 증거로 사용하지 않는다.
