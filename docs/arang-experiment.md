# 아랑전설 별도 시연

사용자가 실행한 `bash scripts/run-arang-experiment.sh -- --save`는 현재 본편과 별도의 **이전 아랑 시연**을 실행한다. 이 시연은 별도 카탈로그와 `user://saves/arang-experiment.json` 저장 슬롯을 사용한다. 현재 본편은 `bash scripts/run.sh`로 실행하며 별도의 본편 저장을 사용한다. 두 실행의 규칙과 진행을 자동으로 혼합하지 않는다.

실행하면 임무 배경과 기본 조작을 설명하는 시작 화면이 표시된다. 저장이 있으면 `Continue Delivery`, 없으면 `Begin Delivery`를 선택한 뒤 보따리 준비 화면으로 들어간다. 읽기만 할 때 기존 저장은 변경하지 않는다.

아랑의 사건을 끝내면 `Next: Stage 2 Preview`로 기존 야광귀 전투 시제품에 들어갈 수 있다. **2장 본편이나 동일 런의 연속 진행은 아니다.** 다음 화면에 별도 시작 보따리와 저장 불가를 명시한다. 기존 아랑 저장·아이템·체력은 야광귀 시제품에 옮기지 않으며, `Exit`로 돌아가면 완료된 아랑 화면을 다시 볼 수 있다. 본편 출시 빌드에는 야광귀 시제품이 포함되지 않는다.

## 영문 표시와 기존 저장

시연의 원본 카탈로그와 그 콘텐츠 해시는 그대로 둔다. 화면에 표시할 아이템·인물·경로·사건·결말 문구는 `game/tests/fixtures/arang-english.json`에서 읽고, 사연은 `arang-story-english.json`을 사용한다. 두 자료는 시연 전용이며 본편 출시에 포함되지 않는다. 모든 표시 필드를 검증한 뒤 적용하므로 문구가 누락되면 시연을 시작하지 않는다. 원본 아이템 효과, 수치, 적의 행동은 바꾸지 않는다.

시연 저장에는 과거 전투 메시지의 원문이 포함될 수 있다. 한글로 기록된 이전 메시지는 화면에서 영문 안내 문구로 대체하지만, 저장된 원문과 진행 상태는 수정하지 않는다. 새 행동의 메시지는 영어로 기록한다. 파일을 읽는 것만으로 기존 저장을 변경하거나 보관하지 않는다.

시연 표시를 상단의 독립된 영역에 배치해 진행 문구와 겹치지 않도록 했다. 사연을 열면 같은 내용을 보여 주던 아래쪽 사연 버튼은 숨기고, 긴 전투 기록은 정해진 영역에서 스크롤한다.

## 실행

```bash
# 기존 시연 저장으로 이어하기
bash scripts/run-arang-experiment.sh -- --save

# 저장 없이 시연하기
bash scripts/run-arang-experiment.sh

# 현재 본편 실행
bash scripts/run.sh
```

저장 없이 실행하는 시연과 본편은 서로 다르다. 별도 시연은 본편의 최신 한기·배율·아이템 보상 구성을 자동으로 포함하지 않는다. 테스트에서는 실제 사용자 슬롯 대신 `build/`의 격리 경로만 사용한다.

`game/tests/arang_english_ui_tests.gd`는 기존 카탈로그로 만든 저장의 해시·파일 바이트 보존, 영문 이름·사연·대화, 긴 기록 스크롤, 세 화면 크기와 실제 결말까지의 진행을 검사한다. `bash scripts/check.sh`는 이 검사와 기존 전투·저장 회귀 검사를 함께 실행한다.
