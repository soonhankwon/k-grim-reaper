# 아랑전설 별도 시연 — 이전 개발 기록

0.14.0부터 본편에도 아랑의 밤을 적용했다. 현재 본편은 [아랑전설 1스테이지](arang-stage-one.md)를 참고한다. 아래는 별도 시연에 대한 이전 기록이다.

신입 차사가 밀양에 부임한 사또를 지키고 아랑의 사연을 듣는 **별도 시연**이다. 실제 설화에는 이본이 있으므로, 대사·전투·동경은 게임을 위한 창작이다. 설화 참고: [한국민족문화대백과 — 아랑 설화](https://encykorea.aks.ac.kr/Article/E0034259), [밀양시 — 아랑사](https://miryang.go.kr/tur/EgovCultureDetail.do?mnNo=30301100000&nmtIdx=980&pageIndex=2&searchCondition=&searchKeyword=&searchKeywordTo=307).

## 실행과 플레이

저장소 루트에서 `bash scripts/run-arang-experiment.sh`를 실행한다. 기본 실행은 저장을 읽거나 쓰지 않는다. 별도 시연 저장으로 이어서 플레이하려면 `bash scripts/run-arang-experiment.sh -- --save`를 사용한다. 저장 위치는 `user://saves/arang-experiment.json`으로 본편 슬롯과 다르다. 첫 사연을 읽고 전투를 시작해 첫 상대를 이긴다. 보상을 처리한 후 증거를 챙기거나 두고 간다. 증거를 챙긴 경우 보관대에 둔 채 확정할 수 있고, 길을 고른 뒤 보따리를 정리할 수 있다.

두 번째 대면에서 전투로 아랑을 진정시키거나, 전투 시작 전 동경을 보따리에 넣었다면 **동경을 보여 주고 듣는다** 버튼으로 아랑의 말을 들을 수 있다. 보관대에 있는 증거는 선택지를 열지 못한다. 아랑은 자신의 사연을 직접 들려주고, 차사는 이를 기록해 전하겠다고 약속한다. 사연·의도·표시된 행동을 확인하며 플레이한다. 두 선택 모두 결과를 확인한 뒤 시연이 끝난다.

## 설계와 한계

- 12개 아이템과 3개 적 정의의 실험 사본을 쓰며 새 에셋을 추가하지 않았다. 동경과 포졸·아랑은 **기존 아이콘과 적 그림을 임시로 재사용**하므로 표현이 이름과 맞지 않는다. 대숲·연못 분기는 현재 대면의 맥락과 기존 적 의도만 바꾼다.
- 원본 `catalog.json`과 일반 게임의 저장은 변경하지 않는다. 시연 카탈로그의 `resolutions`는 공통 `ContentLoader`와 출시용 스키마로 검증되며 콘텐츠 해시에 포함된다. 같은 표를 CSV/Sheets에서도 작성할 수 있다. 본편 카탈로그에는 아직 시나리오 행을 추가하지 않았다.
- `resolve_encounter`는 `BattleSession.submit()`을 거쳐 순수 판정 결과와 이벤트로 재생한다. 증거가 없거나 보관대에 있으면 판정을 거절하며, 재생 중 중복 입력은 잠긴다. 다시 시작할 때 실험 설정을 다시 적용한다.
- 시연은 첫 전투 → 증거 사건 → 선택 경로 → 아랑 대면과 두 결말에 집중한다. 오경 흐름, 한기 슬롯, 증거별 배치 퍼즐, 봉인 패턴, 별도 엔딩 보상, 신규 전용 아트·음향은 아직 구현하지 않았다. 전투 중 재배치도 지원하지 않는다.
- 판정·입력·저장 복구는 본편 엔진에서 지원하지만, 아랑 콘텐츠 자체는 별도 테스트 카탈로그다. 본편으로 채택하려면 스토리와 카탈로그를 기획 확정하고 콘텐츠 변경에 따른 기존 저장 호환 절차와 전용 아트를 준비해야 한다.

`bash scripts/check.sh`의 아랑 시연 검사는 실제 초기 상태에서 첫 전투와 퇴치 경로를 진행하고 증거 휴대·보관·포기, 해원·퇴치, 중복 요청, 표시 시점과 재시작을 확인한다. 별도 임시 슬롯에서 해원 연출 중 복원, 보관 증거, 퇴치 결말, 저장 충돌과 이전 버전 이전도 검사한다. 시연의 실제 화면과 조작은 Godot 실행 화면에서도 확인한다.
