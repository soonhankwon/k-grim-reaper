# 턴 종료 결과 미리보기

전투 중 왼쪽 패널은 **다른 행동 없이 지금 턴을 종료하는 경우**를 보여 준다. 순서별 효과와 대상을 함께 표시하고, 요약에는 플레이어가 실제 잃는 체력의 합, 방어로 흡수한 피해 합, 모든 효과가 끝난 뒤의 체력·승패를 표시한다. 여러 차례의 피해는 각각 합산하며, 회복이 있으면 피해 합과 체력 변화량은 다를 수 있다. 내용이 길면 패널을 스크롤한다. 전투 중에는 배치를 변경할 수 없다.

`BattleSession.preview_end_turn()`은 `display_snapshot()`의 복사본에 실제 명령과 같은 `CombatSimulator.resolve`를 호출한다. 미리보기는 커밋·저장·재생하지 않는다. 연출 재생이나 저장 복구 잠금 중에는 UI가 이를 숨긴다. 재생이 끝나고 표시 스냅샷이 바뀌면 다시 계산한다. 계산 오류나 연쇄 상한 초과 시 부분 수치 대신 이유를 보여 준다.

현재 적 의도는 단일 효과다. 이후 무작위 행동이나 숨은 정보, 다중 의도, 규칙 변경을 도입할 경우 이 미리보기의 결정성과 공개 범위를 다시 정의해야 한다. 자동 판정과 문구가 플레이어에게 이해되는지는 외부 관찰이 필요하다.

`turn_preview_tests.gd`는 실행 결과 일치, 수동·자동 방어, 반응·사망·상한 오류, 표시 상태 및 격리된 저장 파일의 불변성을 검증한다. UI 검사는 재생 중 숨김과 오류 문구를 확인한다. 실제 렌더 스크린샷은 `turn_preview_capture.gd`로 격리된 저장 없는 런에서 생성한다.
