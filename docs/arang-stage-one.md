# 아랑전설 1스테이지 — 0.16.0

신입 차사가 밀양에 부임한 사또를 지키고 아랑의 사연을 듣는 두 대면 분량의 첫 스테이지다. 실제 설화는 이본이 있으며, 대사·전투·동경과 사건 분기는 게임을 위한 창작이다. 참고: [한국민족문화대백과 — 아랑 설화](https://encykorea.aks.ac.kr/Article/E0034259), [밀양시 — 아랑사](https://miryang.go.kr/tur/EgovCultureDetail.do?mnNo=30301100000&nmtIdx=980&pageIndex=2&searchCondition=&searchKeyword=&searchKeywordTo=307).

## 진행

`bash scripts/run.sh`로 본편을 시작한다. 관아의 포졸과 대면하고 보상을 처리한 다음 동경을 챙기거나 두고 간다. 챙긴 동경은 보관대에 둔 채 확정할 수 있고, 경로 선택 후 아랑을 만나기 전에 보따리를 정리할 수 있다.

대숲 경로의 아랑은 체력 30으로 첫 행동에 방어하고 반격이 없다. 연못 경로는 체력 24로 첫 행동이 공격이며 방어를 뚫고 체력 피해를 받으면 행동당 최대 한 번 공격 2로 반격한다. 반격은 치명타에도 발동하고 플레이어의 방어로 막을 수 있다. 경로 선택과 대면 화면에 조건이 표시된다. 두 경로 모두 이후 첫 대면에서 이야기가 끝나며, 경로 UI는 실제로 방문하지 않는 추가 적을 예고하지 않는다.

아랑을 공격해 진정시키거나, 전투 전 동경을 보따리에 넣었다면 **동경을 보여 주고 듣는다**로 억울한 사연을 직접 듣는다. 동경을 두고 가거나 보관대에 둔 경우에는 공격 경로를 선택할 수 있다. 두 결과는 구분해 표시하며 이전 명령을 다시 실행하지 않고 저장에서 복원한다. 첫 전투 이후 보상은 선택 또는 건너뛸 수 있고, 아랑 대면 뒤에는 새 보상을 지급하지 않는다.

## 기존 저장

0.13 카탈로그와 이번 카탈로그는 내용이 다르므로 과거 저장은 자동 이전하지 않는다. 기존 파일을 먼저 보존하고, 게임이 표시하는 복구 창에서 플레이어가 명시적으로 **보관하고 새로 시작**을 선택한 경우에만 저장과 백업을 보관 폴더에 복사하고 새 런을 시작한다. 기존 파일을 닫거나 취소하면 바꾸지 않는다. 테스트는 실제 사용자 폴더가 아닌 격리 슬롯을 사용한다.

## 아트와 범위

포졸·아랑은 신규 정적 픽셀풍 스프라이트, 관아·대숲은 별도의 어두운 배경을 사용한다. 아랑의 두 경로는 같은 인물 그림을 사용한다. 물건·차사는 기존 아틀스를 공유한다. 에셋은 스타일 검증용 정적 시안이며 픽셀 원본의 균일한 32px 격자, 애니메이션과 아랑 전용 음향은 아직 없다. 오경, 전투 중 한기 확산, 증거의 순서 배치 퍼즐, 보상 유물도 아직 구현하지 않았다. 전투 중 재배치는 지원하지 않는다.

`stage_one_ui_tests.gd`는 출시 카탈로그와 격리 저장으로 처음부터 각 경로와 증거 휴대·보관·포기, 해원·퇴치, 연출 중 복원, 완료 후 이어하기, 기존 저장의 보존·명시적 보관을 확인한다. `bash scripts/check.sh`가 이 검사를 포함한다. Windows 내보내기는 별도이며 Windows 실기기와 외부 사용자 플레이 검증은 필요하다.


0.15.0에서는 아랑 대면 준비부터 위쪽 다섯 칸에 [원혼의 한기](frost-grid.md)가 나타나며, 해당 칸에 닿은 무기는 사용 기력이 +1이다.
