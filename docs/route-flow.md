# 0.7.0 갈림길과 진행

첫 길목 승리 후 보상 선택 또는 건너뛰기를 마치고 유품 사건을 처리한 뒤 갈림길로 이동한다. [유품 사건](event-flow.md) 두 선택지는 다음 적의 이름·체력·첫 행동과 그다음 적을 보여 준다. 안개 고갯길은 기존 순서(첫 적 → 매듭 잡귀 → 먹빛 파수꾼), 달그늘 샛길은 마지막 두 적의 순서를 바꾼다. 두 길 모두 기존 적 세 명을 한 번씩 만나며 보상은 첫 두 단계 후 제공한다. 난수·새 적·지도·사연은 없다.

`routes.csv`의 각 행은 경로 이름·설명, 순서대로 연결된 `encounter_ids`, 마지막 단계 전까지의 `reward_ids`를 정의한다. 로더는 경로 2~3개, 공통 첫 길목과 첫 보상, 서로 다른 적 순서, 모든 적의 중복 없는 방문과 유효한 보상 참조를 검증한다. 빈 `routes`는 기존 선형 픽스처를 지원한다. 실제 두 경로는 현재 3전투, 2보상이다.

경로 단계·선택은 값 상태다. `choose_route`는 다른 행동과 같이 `BattleSession.submit()`에서 순수 판정, 저장, 단일 커밋, Action Queue 재생 순서로 처리한다. 갈림길과 재생 중에는 배치를 잠그고, 잘못된 선택이나 이미 지난 선택은 상태를 바꾸지 않는다. 화면은 표시 스냅샷만 읽는다.

0.6 저장은 이전 카탈로그 값이 정확히 같을 때만 이전한다. 이미 첫 길목을 지난 저장은 기존 적 순서를 유지하고, 그 이전 저장은 새 갈림길에서 선택한다. 원본 파일은 읽을 때 수정하지 않고 다음 저장 시 백업한다. 콘텐츠 불일치와 손상은 기존 복구 정책으로 처리한다. [저장 시스템](save-system.md)

경로 순서, 보상 단계, 중복 요청, 저장과 0.6 저장 호환은 `route_tests.gd`, 버튼 경계 및 선택은 `route_ui_smoke.gd`에서 확인한다. 1024×576·1280×720·1920×1080 크기의 자동 UI 검사는 Windows 실기기 확인과 외부 플레이 관찰을 대신하지 않는다.
