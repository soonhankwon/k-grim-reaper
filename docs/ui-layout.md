# 0.10.0 화면과 조작

사용자가 제공한 [Backpack Hero 참고 화면](https://wameprodimages.blob.core.windows.net/images/game/screenshot/3567/w1200/GAME_SCREENSHOT_ss_a9c4024afabe37fe5c1be1aa6f62013369e39da3.1920x1080.jpg.webp)의 상단 가방·하단 전투 무대·우측 턴 종료 구도를 적용했다. 이전의 전투/인벤토리/설명 3열 패널을 교체한다. 게임 화면은 1280×720을 기준으로 비율을 유지하며 창 중앙에 배치한다.

## 시선과 조작

- 상단 얇은 바: 제목, 길목·턴, 사연 기록·길잡이 열기·닫기, 다시 시작.
- 위쪽 중앙: 보자기와 5×4 격자. 큰 물건의 실제 점유 모양, 기력 비용, 이번 턴 사용 여부를 보여 준다.
- 준비·승리 단계의 왼쪽: 임시 보관대와 회전·꺼내기·되돌리기. 보관대 → 보따리 드래그와 선택 → 빈칸 클릭을 모두 지원한다. 12개를 전부 꺼내도 스크롤 안에 머문다.
- 전투 단계: 보따리 물건을 클릭하면 즉시 `use_item` 요청을 제출한다. 마우스를 올려 효과를 먼저 읽을 수 있다. 배치 조작은 잠기고 보관대는 숨긴다.
- 우측: 호버한 물건의 설명과 실제 배치 효과. 아래에 전투 시작/턴 종료/다음 길목 버튼이 같은 자리를 지킨다. 연출 건너뛰기는 재생 중에만 보인다.
- 아래쪽: 왼쪽 차사, 오른쪽 현재 적, 캐릭터 아래 체력·방어, 적 위 다음 행동, 차사 옆 기력. 최근 결과는 짧게 표시한다.

아이템 설명의 첫 줄에 있던 기본 공격/방어 수치는 상세 카드의 계산된 효과와 중복하지 않는다. 본문과 함께 현재 효과, 기본값, 인접 보너스 원인, 사용 가능 여부를 표시한다.

0.4.0에서는 효과 데이터로 발동 시점·대상·수치를 생성한다. 상세 카드는 높이 250px의 스크롤 영역에 두어 복합 효과가 길어져도 턴 버튼을 가리지 않는다. 선택한 물건의 설명은 고정하며, 선택 없이 호버한 설명은 포인터가 나가면 닫힌다. 격자 크기·기력·체력·길목 수는 표시 스냅샷의 설정을 읽는다.

## 단계별 길잡이

우측 정보 영역에서 배치·전투·보상·갈림길·종료 단계의 기본 조작을 안내한다. 기본적으로 보이며 물건에 마우스를 올리거나 선택하면 물건 상세가 우선한다. 상단 길잡이 버튼으로 안내를 숨기거나 상세가 열린 상태에서도 다시 볼 수 있다. 안내는 플레이를 막지 않고 재생 중에는 표시 스냅샷을 따라간다. 세부 계약은 [첫 플레이 길잡이](first-play-guide.md)에 있다.

## 유품 사건

첫 보상 후 하단의 선택지에서 유품을 챙기거나 둔다. 챙기기를 누르면 보관대에 유품이 생기며 보따리에 넣은 뒤 우측 버튼으로 확정한다. 기존 장비를 꺼내거나 회전해 자리를 만들 수 있다. 확정 전 두고 가기를 선택하면 임시 유품만 사라진다. 다음 만남의 반응은 해당 시점의 보따리에 유품이 들어 있는지에 따라 달라진다. [유품 사건](event-flow.md)

## 첫 인도 사연

준비·승리·완료 단계에서 화면 아래의 사연 카드에 현재 기록의 제목과 짧은 문장을 표시한다. 카드를 누르거나 상단 사연 버튼을 누르면 지금까지 공개된 기록을 우측에서 읽을 수 있다. 물건을 살펴보면 상세 정보가 우선하며 기록은 스크롤할 수 있다. 전투 중에는 카드를 숨겨 전투 기록을 표시하고 상단 사연 버튼은 사용할 수 있다. [사연 데이터와 표시](story-flow.md)

## 보상과 재배치

보상 단계에서는 상단 보따리·좌측 보관대를 유지하고 하단 무대를 후보 카드 3개로 바꾼다. 우측에는 후보의 전체 효과 설명, 보상 확정, 보상 받지 않기를 둔다. 선택한 후보는 별도 인스턴스로 보관대에 나타나고 바로 선택되어 빈칸 클릭 또는 드래그로 배치할 수 있다. 정상 배치 전에는 확정 버튼을 비활성화한다. 후보 변경·선택 후 재배치·건너뛰기 안내를 하단에 표시한다.

## 표현 범위

원본 게임의 이미지 자원은 가져오지 않았다. 배경·캐릭터·12개 물건은 공통 색조와 큰 픽셀 실루엣의 생성형 정적 시안으로 교체했다. `game/data/presentation/retro-art.json`은 ID별 아틀스 좌표를 관리하며, 미등록 ID는 기존 도형으로 표시한다. 아이콘은 점유 형태에 맞춰 회전하고 사용 후 어두워진다. 본 시안은 최종 품질이나 애니메이션 완성을 뜻하지 않는다. 근거와 한계는 [아트 참고](art-reference.md)에 있다.

첫 보상 후 하단 무대에서 다음 적의 체력·첫 행동과 이후 적을 비교해 두 경로 중 하나를 선택한다. 세 적과 기존 12개 아이템은 그대로다. 컨트롤러와 모바일 입력은 아직 구현하지 않았다.

## 코드 경계

| 파일 | 책임 |
|---|---|
| `main.gd` | UI 입력을 배치 모델 또는 세션 요청에 연결하고 표시 스냅샷을 바인딩 |
| `event_panel.gd` | 사건 선택과 후속 반응 표시, 세션 요청 연결 |
| `story_book.gd` / `story_panel.gd` | 표시 스냅샷에 맞춘 읽기 전용 기록과 스크롤 |
| `guide_panel.gd` | 현재 표시 단계에 따른 비차단 안내 |
| `battle_layout.gd` | 화면 구성, 비율 유지, 보자기·배경 |
| `inventory_board.gd` | 점유 표시, 보드 입력, 보관대에서 시작한 드래그의 좌표 변환 |
| `stash_slot.gd` / `item_icons.gd` | 보관대 슬롯과 공통 픽셀 아이콘 |
| `road_view.gd` | 캐릭터 표현. 재생 명령의 틴트 대상 |
| `effect_text.gd` | 공통 효과 어휘로 대상·시점·수치·태그 조건 표시 |

시뮬레이션·재생의 경계를 유지한다. 체력바, 기력, 아이템 소모·사용 표시와 상세 정보는 `display_snapshot()`의 같은 단계에서 갱신한다. 미리보기는 공통 순수 계산을 읽으며 전투를 실행하거나 상태를 변경하지 않는다. 시간 처리는 기존 Action Queue만 소유한다. 호버·드래그 콜백에 별도 전투 규칙이나 연출 타이머를 만들지 않는다.

## 검증

`bash scripts/check.sh`에 기존 판정·연쇄·재생 검사와 UI 통합 검사가 포함된다. UI 검사는 보드 드래그, 보관대 드래그, 회전 취소, 직접 클릭 공격, 재생 중 중복 클릭, 체력바 반영 시점, 소비 표시를 확인한다. 1024×576/1280×720/1920×1080에서 12개 설명 창이 화면 안에 있고 턴 버튼을 가리지 않는지, 축소 후 드래그 좌표가 유지되는지도 확인한다. 실제 운영체제별 입력·디스플레이 배율은 별도 수동 검증이다.
