# 야광귀 설화 전투 시제품

야광귀가 신발을 노리는 동안 체의 쳇눈으로 시간을 벌고 새벽까지 버티는 **별도 전투 시제품**이다. 본편 2스테이지나 저장 기능은 아직 아니다. 겨울 초가마을 배경, 외눈 야광귀, 둥근 체의 정적 픽셀풍 시안을 실제 시제품에 사용한다. 차사는 기존 아틀스를 재사용하며 서로 마주 보도록 배치한다. 개별 저해상도 픽셀 원본 정리, 애니메이션·환경음은 아직 제작하지 않았다. [제작 기록과 프롬프트](art-direction.md)

아랑 별도 시연을 완료한 뒤에도 `Next: Stage 2 Preview`로 이 시제품을 열 수 있다. 별도 초기 보따리로 시작하고 저장되지 않으며 아랑의 저장은 그대로 둔다. 해외 시연을 위해 이 시제품의 표시 문구와 전투 기록은 영어로 표시한다. [아랑 시연](arang-experiment.md)

```bash
bash scripts/run-yagwang-experiment.sh
```

Godot 4.7.2가 필요하다. 시제품은 사용자 저장을 읽거나 쓰지 않으며 다시 시작하면 처음부터 진행한다. `bash scripts/run-yagwang-experiment.sh -- --capture`는 첫 화면을, `-- --preview-capture`는 신발을 위로 옮기는 예상 화면을 `build/`에 캡처한다. 시제품 데이터와 실행 스크립트는 출시 PCK에서 제외한다.

## 플레이

- 초기 보따리는 빈 2×2 공간이 없다. 예를 들어 갓을 선택해 **꺼내기**를 누르고 보관대의 체를 그 자리에 배치한다. 다른 재배치도 가능하며 체 없이 시작할 수도 있다.
- 시작 배치의 맨 아래 줄은 위험 구역으로 표시한다. **신발이 한 칸이라도 이 줄에 닿으면 신발을 우선 노린다.** 신발을 모두 위로 옮기거나 보관대에 두면 신발을 제외한 물건 중 가장 아래에 닿은 물건을 대신 노린다. 동점은 인스턴스 ID 오름차순이다. 보호된 신발만 남아 있다면 목표는 없다. 목표가 소모 등으로 사라지면 같은 규칙으로 다시 정한다.
- 보드의 `!`와 외곽선은 현재 목표다. 물건을 끌어다 유효한 칸에 놓기 전에는 금색 테두리와 **배치 예상** 문구로 바뀔 목표를 보여 준다. 배치가 불가능하면 현재 목표를 유지한다. 전투 중 배치는 잠긴다.
- 야광귀는 매 턴 공격 5를 하고, 취소되지 않은 적 행동 3회 후 표시된 물건을 강탈한다. 도난 물건은 보관대에 놓여 효과가 꺼지고, 다음 턴부터 전투 동안 기력이 1 감소한다. 전투 중에는 배치를 바꿀 수 없다.
- 보따리에 넣은 체를 전투 중 클릭하면 기력 1을 사용하고 **다음 적 행동과 탐색 진행을 한 번 취소**한다. 전투당 한 번만 사용할 수 있다. 적에게 치명적인 공격을 가해 전투가 끝나면 취소를 소비할 필요가 없다.
- 6턴의 적 행동이 끝났을 때 살아 있으면 닭 울음과 함께 승리한다. 그 행동에서 플레이어가 사망하면 새벽 승리는 발생하지 않는다. 공격으로 먼저 이겨도 된다. 어느 승리든 빼앗긴 물건은 원래 위치로 돌아온다.
- 목표, 남은 강탈 횟수, 새벽까지 남은 턴과 취소된 다음 행동을 화면에 표시한다. **지금 턴 종료하면** 미리보기는 같은 판정으로 공격·강탈·기력 감소·새벽 승리를 계산한다.

수치는 재미를 검증하기 위한 초기 값이며 확정 밸런스가 아니다. 지금은 칸 봉인, 인접 무기로 신발을 둘러싸 보호하는 판정, 도난으로 인한 적 회복, 무작위 이동, 다단 히트 유인, 다수 적과 회피율이 없다.

## 구조와 데이터 경계

본편 `BattleSession.submit()`에서 입력 잠금과 커밋·Action Queue 재생을 담당한다. 실험 규칙은 데이터와 스냅샷을 받아 복사본을 계산하고 원인 ID와 이벤트별 표시 스냅샷을 반환한다. 기본 공격·피해·사망과 턴 종료는 기존 `CombatSimulator`에 위임하며, 체에 의해 적 행동을 건너뛰는 옵션은 순수 판정에만 전달한다. 재생기는 이벤트를 보여 줄 뿐 상태를 판정하지 않는다. 미리보기에도 같은 실험 규칙을 사용한다.

`game/tests/fixtures/yagwang-experiment.json`은 기존 `ContentLoader`의 스키마 검증을 통과하는 별도 실험 카탈로그다. 태그·모양·효과와 적 공격을 여기에 둔다. 실험 전용 `yagwang-rules.json`은 대상 태그·유인 태그·위험 구역 행 수·카운트다운·새벽·기력 감소를 담으며 시제품 규칙이 범위를 검증한다. **이 두 파일은 Google Sheets 출시 파이프라인의 새 스키마가 아니다.** 본편에 도입할 때는 범용 연산·트리거·상태와 CSV/JSON 스키마, 밸런싱 시트, 저장 버전·복구 검증을 함께 설계해야 한다.

실험 규칙은 저장 서비스가 없는 세션에만 설치하며, 설치 후 저장 서비스가 붙더라도 행동·배치·새 저장을 거절한다. 저장 기능은 구현하지 않았으므로 실험 진행을 복구하지 않는다. 기존 본편의 저장은 읽거나 덮어쓰지 않는다.

## 검증

`bash scripts/check.sh`에 시제품 검사가 포함된다. 대상 우선순위·체의 공간 제약과 행동 취소·중복 사용 거절·강탈·기력 저하·새벽 및 공격 승리·패배 우선순위·물건 반환, 같은 판정의 미리보기와 실제 결과, 세 화면 크기, 재생 중 중복 입력·건너뛰기·재시작·장면 종료 및 저장 차단을 검사한다. 자동 검사는 플레이어가 퍼즐을 이해하고 재미있게 느끼는지에 대한 외부 관찰을 대신하지 않는다.


전투 중에는 야광귀 쪽에서 현재 목표까지 붉은 시선이 이어진다. 목표 지정 이벤트 재생 시 점등되며 강탈 뒤에는 사라진다. 등장 화면과 소리는 [연출 파이프라인](cinematic-presentation.md)을 따른다.
