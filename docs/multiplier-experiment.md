# 정수 배율 시너지 실험

출시 콘텐츠와 사용자 저장을 건드리지 않는 테스트 모드다. 기존 옥가락지를 실험용 2배 수정 아이템으로 사용하고, 기존 봉인부의 +2를 더한 뒤 검의 공격을 두 배로 만든다. 시작 배치에서 **(6 + 2) × 2 = 16**이며, 검의 상세 화면에 계산식과 두 출처가 표시된다. 실험의 옥가락지는 기존 아이콘을 재사용한다.

```bash
bash scripts/run-multiplier-experiment.sh
```

Godot 4.7.2가 필요하다. 상단에 `배율 실험 · 저장 안 함`이 표시되며 기존 사용자 저장을 읽거나 쓰지 않는다. 봉인부를 맨 윗줄 왼쪽에서 두 번째 칸에 옮기면 12, 옥가락지를 맨 윗줄 맨 왼쪽에 옮기면 8이 된다. 배치 이전·미리보기·전투 결과를 비교해 보자. 다시 시작하면 배치가 초기화된다.

`bash scripts/run-multiplier-experiment.sh -- --capture`는 실제 Godot 화면을 `build/multiplier-experiment-screen.png`에 저장하고 종료한다. 이 모드와 테스트 데이터는 출시 PCK에서 제외한다. Windows 실기기·외부 플레이어의 이해도·재미는 아직 검증하지 않았다.

아이템을 선택하면 보따리에 고정 증가 `+`, 배율 `×`, 조건 `○` 연결이 표시된다. 다른 칸을 가리켰을 때는 유효한 배치의 연결을 점선으로 미리 보여 준다. [연결 표시 설명](synergy-visualization.md)

CSV/JSON 및 기획 시트로 작성하는 방법과 계산·범위·그룹·정수 한도 규칙은 [데이터 파이프라인](data-pipeline.md)에 있다. `multiplier_tests.gd`는 계산식·출처, 데이터 유효성, 대각선과 대상 조건, 중첩 순서, 오버플로·죽음·반응·저장 롤백, UI·재시작을 검증한다.
