# 보따리 시너지 연결 표시

보따리에서 아이템을 선택하면 그 물건과 **직접 연결된** 효과의 출처와 대상을 표시한다. 화살표는 출처에서 대상 방향이며, 테두리와 기호는 다음을 의미한다.

- `+`: 해당 물건의 효과에 적용되는 고정 증가.
- `×`: 해당 물건의 효과에 적용되는 정수 배율.
- `○`: 주변 물건을 세는 효과의 조건에 맞는 물건. 조건 자체를 뜻하며 피해 반응이 이미 발생했다는 뜻은 아니다.

상세 카드에는 출처 → 대상, 상하좌우·대각선·주변 8칸, 발동 시점과 수치를 적는다. 조건 일치 물건이 최대 개수보다 많으면 모든 일치 물건을 `○`로 표시하고 **최대 N개**를 함께 적는다. 어느 특정 물건이 초과분으로 제외됐다고 임의 지정하지 않는다. 자기 자신에게 적용되는 수정은 해당 물건의 기호와 상세 문구로 표시한다. 연결이 많으면 카드에서 스크롤한다.

확정 배치는 금색 실선, 유효한 **배치 예상**은 청록 점선과 위치 미리보기로 구분하고 상세 계산도 예상 배치에 맞춘다. 유효하지 않은 배치는 연결을 표시하지 않는다. 보관 중인 물건은 유효한 칸을 가리켜야 배치 예상이 생긴다. 전투 연출 중에는 연결을 숨기며 연출 종료·건너뛰기 후 표시 스냅샷의 연결을 다시 보여 준다. 예측이나 연결 표시는 상태·이력·저장을 변경하지 않는다.

## 계산 경계

`EffectApplier.plan()`이 실제 수치 계산에 사용한 수정 출처, 적용된 범위, 조건 일치 목록을 값으로 함께 반환한다. `InventoryRules.synergy_links()`는 이 결과만 이용해 선택 물건의 직접 연결을 투영한다. 스택 그룹에서 탈락한 수정은 표시하지 않으며, 같은 물건의 다칸 접촉을 여러 물건으로 세지 않는다. 다칸 물건이 상하좌우와 대각선에 모두 닿는 경우 선은 **실제 효과의 범위에 맞는 접점**에 그린다. 계산 실패 시 부분 연결을 숨기고 오류를 표시한다.

표시는 현재 배치에서 조건이 충족된 효과 계획이다. `사용`, `턴 종료`, `피해 반응` 같은 **발동 시점은 상세 카드에 명시**하며 미래에 무조건 발동한다고 보장하지 않는다. 보따리 안에 없는 물건은 계산하지 않는다. 판정은 기존 `BattleSession.submit()`과 순수 FIFO를 유지하고, 시각화는 표시 스냅샷과 가상의 배치 복사본만 읽는다. 애니메이션이나 전투 중 재배치는 도입하지 않았다.

`synergy_tests.gd`는 고정 증가·배율 출처, 대각선 접점, 그룹 중복, 자기 수정, 조건 상한, 유효·무효 예상, 취소·재시작, 재생·건너뛰기와 창 크기를 확인한다. 저장 없는 배율 실험에서 `bash scripts/run-multiplier-experiment.sh -- --preview-capture`를 실행하면 `build/synergy-preview-screen.png`를 만든다. 사람의 판독성과 Windows 실기기는 별도 검증이 필요하다.
