# 보따리 시너지 연결 표시

보따리에서 아이템을 선택하면 그 물건과 **직접 연결된** 효과의 출처와 대상을 먹색 외곽의 곡선 실로 표시한다. 작은 실 끝은 출처, 큰 매듭은 대상이다. 아이템 위에 수학 기호를 덧씌우지 않으며 실의 색은 다음을 의미한다.

- 금색: 해당 물건의 효과에 적용되는 고정 증가.
- 청색: 해당 물건의 효과에 적용되는 정수 배율.
- 붉은색: 주변 물건을 세는 효과의 조건에 맞는 물건. 조건 자체를 뜻하며 피해 반응이 이미 발생했다는 뜻은 아니다.

상세 카드 상단에는 실제 적용 순서대로 기본값, 출처 아이콘과 증가·배율, 최종값을 표시한다. 덧셈과 배율이 함께 있으면 괄호로 순서를 명확히 한다. 아이콘에는 원본 아이템의 툴팁과 접근성 이름을 붙인다. 상세 연결 문구에는 출처 → 대상, 상하좌우·대각선·주변 8칸, 발동 시점과 수치를 적는다. 조건 일치 물건이 최대 개수보다 많으면 모든 일치 물건을 붉은 실로 표시하고 **최대 N개**를 함께 적는다. 어느 특정 물건이 초과분으로 제외됐다고 임의 지정하지 않는다. 자기 자신에게 적용되는 수정은 매듭과 상세 문구로 표시한다. 연결이 많으면 카드에서 스크롤한다.

확정과 유효한 **배치 예상**은 각각 범례·상세 메타의 `Preview` 및 가상 아이템 위치로 구분하고 상세 계산도 예상 배치에 맞춘다. 예상 실은 같은 종류의 색을 밝게 표시한다. 실은 현재 정적인 픽셀 선화이며 연속 흔들림이나 파티클은 아직 없다. 유효하지 않은 배치는 연결을 표시하지 않는다. 보관 중인 물건은 유효한 칸을 가리켜야 배치 예상이 생긴다. 전투 연출 중에는 연결을 숨기며 연출 종료·건너뛰기 후 표시 스냅샷의 연결을 다시 보여 준다. 예측이나 연결 표시는 상태·이력·저장을 변경하지 않는다.

## 계산 경계

`EffectApplier.plan()`이 실제 수치 계산에 사용한 수정 출처, 적용된 범위, 조건 일치 목록을 값으로 함께 반환한다. `InventoryRules.synergy_links()`는 이 결과만 이용해 선택 물건의 직접 연결을 투영한다. 스택 그룹에서 탈락한 수정은 표시하지 않으며, 같은 물건의 다칸 접촉을 여러 물건으로 세지 않는다. 다칸 물건이 상하좌우와 대각선에 모두 닿는 경우 선은 **실제 효과의 범위에 맞는 접점**에 그린다. 계산 실패 시 부분 연결을 숨기고 오류를 표시한다.

표시는 현재 배치에서 조건이 충족된 효과 계획이다. `사용`, `턴 종료`, `피해 반응` 같은 **발동 시점은 상세 카드에 명시**하며 미래에 무조건 발동한다고 보장하지 않는다. 보따리 안에 없는 물건은 계산하지 않는다. 판정은 기존 `BattleSession.submit()`과 순수 FIFO를 유지하고, 시각화는 표시 스냅샷과 가상의 배치 복사본만 읽는다. 새로 형성된 연결에는 성공적인 배치 직후 짧은 금빛 펄스를 표시한다. 전투 중 재배치는 도입하지 않았다.

`synergy_tests.gd`는 고정 증가·배율 출처, 대각선 접점, 그룹 중복, 자기 수정, 조건 상한, 유효·무효 예상, 취소·재시작, 재생·건너뛰기와 창 크기를 확인한다. 저장 없는 배율 실험에서 `bash scripts/run-multiplier-experiment.sh -- --preview-capture`를 실행하면 `build/synergy-preview-screen.png`를 만든다. 사람의 판독성과 Windows 실기기는 별도 검증이 필요하다.

## 배치 피드백

드래그하면 잡은 지점을 기준으로 아이템이 1.1배 확대되어 커서를 따라가고 그림자를 표시한다. 기존 자리는 어둡게 남겨 원래 배치와 유효·무효 예상 칸을 확인할 수 있다. 배치와 저장이 성공하고 실제 위치나 회전이 바뀐 경우에만 0.32초 스냅 및 효과음을 재생한다. 위치 변경 전후의 같은 `InventoryRules.synergy_links()` 결과에 새 연결이 있으면 출처·대상의 금빛 테두리가 펄스한다.

피드백 전용 `ActionQueue`와 `LayoutFeedbackCommand`가 Tween의 완료·중단을 소유한다. 실패, 동일 위치, 저장 실패는 성공 효과를 내지 않는다. 새 선택·회전·취소·되돌리기·보관·전투 시작·재시작·화면 종료와 시간 초과는 진행 중 연출을 정리한다. 판정, 배치 저장, 사용자 입력은 애니메이션을 기다리지 않으며 미리보기 역시 복사본만 읽는다. 스냅 소리는 기존 소리 버튼을 따르는 자체 합성 시안이다. 자동 검사는 `game/tests/interaction_feedback_tests.gd`, 화면 확인은 `game/tests/interaction_feedback_capture.gd`를 사용한다.
