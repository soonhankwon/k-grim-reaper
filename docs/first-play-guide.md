# 0.8.0 첫 플레이 길잡이

우측 길잡이는 현재 단계에서 필요한 행동을 짧게 안내한다. 보따리 배치와 상하좌우 인접, 아이템 클릭과 기력·적 행동, 보상 선택·배치·확정, 길목 이동과 경로 선택, 패배 후 재도전을 다룬다. 보상 선택 전과 후에는 다른 문구를 보여 준다. 최종 완주 방법을 강제하거나 특정 아이템·배치를 정답으로 지정하지 않는다.

- 기본으로 보이며, 상단 **길잡이** 버튼으로 숨기거나 다시 연다. 화면을 다시 열면 표시 상태에 맞는 안내가 기본으로 나타난다. 열림 여부는 개인 설정으로 저장하지 않는다.
- 물건 또는 보상 후보를 살펴볼 때는 상세 정보가 우선한다. 상세가 보이는 중에도 길잡이 버튼을 누르면 안내를 볼 수 있고, 다른 물건에 포인터를 올리면 다시 상세가 표시된다.
- 진행을 가로막거나 입력을 유도하는 모달은 없다. 보따리와 주요 버튼은 가리지 않는다. 실제로 게임을 진행하면 안내가 따라 바뀐다.
- `GuidePanel`은 `BattleSession.display_snapshot()`의 단계와 재생 여부를 표시만 한다. 연출이 진행 중일 때 확정 상태를 미리 표시하지 않고, 저장·보상·배치·전투 행동을 직접 수행하지 않는다. 기존 저장 포맷과 콘텐츠 해시는 그대로다.
- 저장 복구 등 진행이 잠긴 경우 안내도 그 상태를 알리며 저장 복구 절차를 우회하지 않는다.

`guide_ui_smoke.gd`는 열기·닫기, 물건 상세 우선순위, 화면 경계, 배치→전투→보상→승리→갈림길→준비 전환, 연출 이전 승리 비노출, 저장 불변 및 경로 선택 후 재실행을 확인한다. 출시 PCK에서도 첫 안내 표시를 검사한다. 실제 초보 플레이어의 이해와 Windows 입력·화면 배율 확인은 아직 필요하다.
