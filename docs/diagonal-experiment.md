# 대각선 효과 실험

현재 출시 콘텐츠를 변경하지 않는 별도 테스트 모드다. 기존 봉인부를 **실험용 대각 부적**으로 바꾸어 대각선으로 닿는 무기만 공격 +2를 받게 했다. 나머지 물건과 적은 기존 테스트 데이터를 재사용하고, 갓을 보관대로 옮겨 시작 배치를 마련했다. 현재 출시 아이템의 효과나 기존 저장을 바꾸지 않는다.

```bash
bash scripts/run-diagonal-experiment.sh
```

Godot 4.7.2가 필요하다. 상단에 `대각선 실험 · 저장 안 함`이 표시되며 기존 사용자 저장을 읽거나 쓰지 않는다. 초기 검은 대각선 접촉으로 공격 8이다. 부적을 맨 윗줄의 왼쪽에서 두 번째 칸으로 옮기면 공격이 6으로 줄어든다. 부적을 선택해 범위를 읽고 배치를 옮겨 확인한 뒤 전투에서 공격 수치를 비교해 볼 수 있다. 다시 시작하면 실험이 초기화된다.

`bash scripts/run-diagonal-experiment.sh -- --capture`는 실제 Godot 렌더 화면을 `build/diagonal-experiment-screen.png`에 저장하고 종료한다. 이 실험은 `game/tests/fixtures/diagonal-experiment.json`을 사용하므로 출시 PCK에 포함되지 않는다. Windows 실기기와 외부 플레이어 관찰은 아직 하지 않았다. 대각선이 충분히 읽히고 재미있는지는 테스트 결과를 관찰한 뒤 결정한다.

스키마, CSV·JSON, 범위 정의와 기획 시트 사용법은 [데이터 파이프라인](data-pipeline.md)을 따른다. `diagonal_tests.gd`는 회전·불규칙 모양·여러 접점 중복 제거, 태그·상한, 데이터 유효성·CSV/JSON, 미리보기와 전투 결과, 표시 시점을 검증한다.
